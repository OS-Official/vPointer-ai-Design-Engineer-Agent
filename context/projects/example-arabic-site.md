A fictional brief for an Arabic-only marketing site without a brand pack, so the agent asks before choosing fonts or colours.

A five-page Arabic (RTL) site for a small neighbourhood bakery: home, menu, branches, about, contact.

## Stack
HTML + Tailwind CSS v4. Hosted on Vercel or Cloudflare Pages.

## Copy
Professional Modern Standard Arabic, no diacritics.
